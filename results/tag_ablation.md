# 保留词性标签的代价（对照实验）

## 1. 词表与稀疏度

| 口径 | token 数 | 词型数 | 相对干净语料 |
|---|---|---|---|
| 原始（含句子编号、词性、`[`/`]` 标注） | 7286876 | 295610 | 2.08× |
| 保留词性（`词/词性`） | 7286875 | 164533 | 1.16× |
| 去标签后（本项目采用） | 7286875 | 141990 | 1.00× |

* 句子编号共 123882 个（每行一个），作为词级 token 时是 123882 个只出现一次的“词型”。
* 词三元组类型：干净语料 4515472 → 带标签 4596790（**1.018×**，只多了 1.8%）。也就是说，同一模式被切碎带来的计数稀释**并不严重**；保留标签的主要代价在词表身份与生成形态上（下表与第 3 节）。

## 2. 标签携带多少信息

* 以词为条件的标签条件熵 H(tag|word) ≈ **0.4306 bits/token**（42 种词性，加性平滑估计）：标签本身几乎被词决定。
* “取该词最常见词性”这一朴素基线在验证集上的准确率 = **91.51%**。

## 3. 标签会泄漏到生成结果里

同一个前缀、同样的解码参数（T=0.7, top-k=5, seed=7）：

* 带标签训练的模型（3-gram，词表 65533，训练 10.19s）：

  ```
  在阳光明媚的五月，我们学校胜利召开了的/u《/w关于/p对/p在/p印尼/ns的/u外汇/n储备/vn，/w使/v我/r对/p这/r一/m天/q晚上/t，/w我/r想/v，/w这/r是/v一/m次/q
  ```

  其中含 `/` 的“伪词” token 数：**25/25**。

* 去标签后的模型：

  ```
  在阳光明媚的五月，我们学校胜利召开了全国政协委员的意见和要求。”这是一种“两个根本性转变，实现了。
  ```

> 注：带标签模型的 PPL = 234.09，但这个数字与干净模型**不可比**：它的词表同样被 65,533 的上限截断，2.71% 的验证 token 落到 `<unk>`，而 `<unk>` 在带标签语料里是高频符号。这里引用它的目的不是比 PPL，而是说明**标签会改变输出形态**——生成出的 100% 的 token 都带词性标注。
